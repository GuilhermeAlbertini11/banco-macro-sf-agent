# Banco Macro — Salesforce MDA

Projeto de análise e performance para o cliente Banco Macro, plataforma Salesforce.

## Estrutura

- `docs/` — documentos de capacitação, specs, apresentações
- `metadata/` — arquivos de metadados da org Salesforce (XML, JSON, YAML)
- `links/` — arquivos .md com links e referências externas

## Contexto

- Cliente: Banco Macro
- Projeto: MDA (Multi-Device App)
- Foco: QA Performance, Scale Test, Scale Center
- Equipe: Salesforce Professional Services
